## 0. 사용자 확정 방침 (2026-06-01)

1. **공고 등록 · 이력서 업로드 = 모바일 제외.** HR이 데스크톱에서 처리.
2. 모바일은 **상태 변경 · 내용 확인** 위주.
3. **관리자 메뉴는 모바일 필수.** 급할 때 모바일로 접속해 **토큰 충전·환불** 등 운영 처리.
4. 네비게이션은 **햄버거 메뉴만** (하단 탭바 X).
5. 데스크톱 전용 화면은 모바일 진입 시 **"PC에서 이용" 안내문** 표시.

## 1. 누가 모바일로 들어오나?

| 사용자 | 모바일 사용 | 핵심 동기 |
|---|---|---|
| **외부 후보자** | 🔴 매우 높음 | 메일 링크 받고 **폰에서 면접 진행** |
| **채용 담당자 (member/org_admin)** | 🟡 중간 | 이동 중 **현황 확인·결과 열람·상태 변경·알림 대응** |
| **시스템 관리자** | 🟡 중간 | 급할 때 **토큰 충전·환불 등 운영 처리** |

**원칙**: 모바일 = **확인 · 상태변경 · 급한 운영처리** / 데스크톱 = **생성 · 업로드 · 복잡한 설정**.

## 2. 필수 기능 (모바일 1급 — 반드시 잘 동작)

### A. 후보자 면접 흐름 *(이미 완료 — 유지·점검만)*
- `/interview/[token]` — AI 채팅 면접
- `/interview/[token]/me` — 본인 데이터 조회/삭제
- `/interview/[token]/appeal` — 이의제기
- `/schedule/[token]` — 1차 면접 일정 선택
- `/invite/[token]` — 멤버 초대 수락
- `/verify`, `/password-reset`, `/login` — 인증 진입점

### B. 담당자 — 확인 + 상태변경 흐름 (신규 모바일 대응 필요)
| 화면 | 모바일 핵심 동작 | 비고 |
|---|---|---|
| `/` 대시보드 (공고 목록) | 공고 카드 세로 스택, D-day·인원 한눈에 | 점검 |
| `/jobs/[id]` 공고 상세 | 후보자 리스트 + 전형 단계 현황 **열람** | 🔴 **스크린샷 깨진 화면 — 1순위** / ⛔ 이력서 업로드 UI는 모바일에서 숨김 |
| `/candidates/[id]` 후보자 상세 | 서류평가·면접 결과·대화록 **열람** + **단계변경·합불결정** | 점수/추천/요약 우선 |
| `/notifications` 알림 | 합류 요청·면접 완료 알림 확인 | 벨 + 목록 |

### C. 담당자 — 가벼운 "상태변경" 액션 (모바일 필수)
- 후보자 **단계 변경 / 합·불 결정** (모달 → 풀스크린 시트)
- **면접 링크 발송** (버튼 한 번)
- 합류 요청 **승인/거절** (`/org/members?tab=requests`)

### D. 시스템 관리자 — 급한 운영 처리 (모바일 필수) ⭐신규 승격
| 화면 | 모바일 핵심 동작 | 비고 |
|---|---|---|
| `/admin/orgs` 법인 관리 | **토큰 충전 / 환불** (사유 입력) · 법인 정지/재개 | 🔴 표 → 카드형 재설계 필요 |
| `/admin/dashboard` 운영 | 마이너스 잔액·큐·정지 법인 **현황 확인** | 읽기 위주 |
| `/admin/users` 사용자 | 강제 로그아웃·비번 리셋 등 급한 대응 | 카드형 + 핵심 액션만 |

> 토큰 충전/환불은 입력이 단순(금액 + 사유)하므로 모바일 시트로 충분히 가능.

## 3. 부가 기능 (모바일 2급 — 읽기 가능, 작성은 데스크톱)

| 화면 | 모바일 처리 방침 |
|---|---|
| `/jobs/[id]/compare` 후보자 비교 | 가로 grid → 카드 세로 스택 (읽기) |
| `/jobs/[id]/report` 공고 리포트 | 읽기 전용, 가로 스크롤 허용 |
| `/account` 계정/세션 | 세로 폼 정리 (비번 변경 등) |
| `/org/tokens` 토큰 지갑 | 잔액·경고 배너 읽기 필수, 표는 가로 스크롤 |
| `/org/members` 멤버 관리 | 합류 요청 승인만 모바일, 나머지 열람 |
| `/admin/metrics`, `/admin/audit` | 읽기 위주, 표 가로 스크롤 |

## 4. 모바일 제외 (데스크톱 전용 — "PC에서 이용" 안내)

> 깨짐만 방지하고, 모바일 최적화 투자는 안 함. 들어가면 안내문 노출.

- ⛔ **`/jobs/new` 공고 등록** — 데스크톱 전용 (사용자 확정)
- ⛔ **이력서 PDF 업로드** (`/jobs/[id]` 내 업로드 영역) — 데스크톱 전용 (사용자 확정)
- `/jobs/[id]/edit` 공고 수정 — 데스크톱 권장
- `/org/smtp` 메일 서버 설정 — 데스크톱 권장
- 사람 면접관 메모/스코어카드 입력 — 데스크톱 권장 (열람만 모바일)
- `/admin/pricing` 단가, `/admin/candidates`, `/admin/locks`,
  `/admin/orgs/[id]/transfer-admin`, CSV export 등 저빈도 운영 도구

## 5. 네비게이션 구조 변경 (모바일 핵심 토대)

현재 `NavBar` 는 **데스크톱 가로 드롭다운만** 있고 **모바일 햄버거 메뉴가 없음** → 모바일 메뉴 깨짐의 근본 원인.

**제안**:
- `< sm` (모바일): **햄버거 → 슬라이드/풀스크린 메뉴**
  - 상단 고정: 로고 · 알림벨 · 프로필
  - 메뉴 안 세로 리스트 (역할별):
    - 담당자: 대시보드 · (법인: 토큰/멤버) · 계정
    - **시스템관리자: 운영 · 법인(토큰충전/환불) · 사용자 · 메트릭** ← 모바일에서도 노출
- (선택) 하단 탭바 — §6 질문 1 참조
