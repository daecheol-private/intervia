# 줌(Zoom) 연동 가이드

회사 줌 계정을 Intervia에 한 번만 연결해 두면, 온라인 면접 때 **버튼 한 번**으로 줌 회의 링크가 자동으로 만들어집니다.
설정은 처음 한 번만 하면 되고, **약 10분** 정도 걸립니다. 코딩 같은 건 전혀 필요 없습니다.

> 만들어진 줌 링크는 후보자와 면접관에게 메일로 자동 발송됩니다.
> 후보자는 줌 계정이 없어도 링크만 누르면 참여할 수 있습니다.

---

## 시작하기 전에

- 회사 줌 계정의 **관리자 권한**이 필요합니다. (회사 대표 계정 또는 관리자 계정)
- 아래 과정은 **딱 한 번만** 하면 됩니다. 이후로는 면접마다 버튼만 누르면 됩니다.

---

## 1단계 · 줌에서 연결 정보 만들기

### ① 줌 개발자 페이지 접속

1. 인터넷 주소창에 **marketplace.zoom.us** 를 입력해 접속합니다.
2. 오른쪽 위 **Sign In(로그인)** 을 눌러 **회사 관리자 계정**으로 로그인합니다.

   ⚠️ 꼭 회사 관리자 계정으로 로그인하세요. 그래야 회사 회의가 만들어집니다.

### ② 새 앱 만들기

1. 오른쪽 위 **Develop** → **Build App** 을 차례로 누릅니다.
2. 여러 종류 중 **"Server-to-Server OAuth"** 를 찾아 **Create(만들기)** 를 누릅니다.
3. 앱 이름을 적습니다. (예: `Intervia 면접`) → **Create**

### ③ 연결 정보 3개 복사하기 ⭐ 가장 중요

앱을 만들면 화면에 아래 **3개의 값**이 나옵니다.

- **Account ID**
- **Client ID**
- **Client Secret**

📋 이 3개를 메모장 등에 그대로 복사해 두세요. (잠시 후 Intervia에 붙여넣습니다)

> 🔒 **Client Secret은 비밀번호와 같습니다.** 다른 사람에게 공유하지 마세요.

### ④ 빈 칸 채우기

왼쪽 메뉴 **Information(정보)** 에서 빨간 표시가 된 칸(회사명, 담당자 이름·이메일 등)을 채웁니다.
형식적인 내용이라 정확히 적기만 하면 됩니다.

### ⑤ 권한 추가하기 ⭐ 필수

1. 왼쪽 메뉴 **Scopes** → **Add Scopes** 를 누릅니다.
2. 검색창에 **meeting** 을 입력합니다.
3. **회의 만들기 권한**(이름에 `meeting`과 `write`가 들어간 항목)을 골라 체크하고 추가합니다.

> 이 권한이 있어야 줌 회의를 자동으로 만들 수 있습니다. 빠뜨리면 나중에 오류가 납니다.

### ⑥ 켜기(활성화)

왼쪽 메뉴 **Activation** → **Activate(활성화)** 버튼을 누릅니다.

- 버튼이 안 눌리면, 앞 단계에서 **빨간 표시된 빈 칸**이 남아 있는 것입니다. 채운 뒤 다시 누르세요.
- "Activated" 라고 나오면 줌 쪽 준비는 끝입니다.

---

## 2단계 · Intervia에 연결 정보 입력하기

1. Intervia에 **관리자 계정**으로 로그인합니다.
2. **설정 → 줌 연동** 화면으로 들어갑니다.
3. 1단계 ③에서 복사해 둔 값 3개를 각 칸에 붙여넣습니다.
   - Account ID / Client ID / Client Secret
4. **저장** 을 누릅니다.
5. **연결 테스트** 버튼을 눌러 "연결 성공"이 나오는지 확인합니다.

이걸로 연동이 끝났습니다. 🎉

---

## 사용 방법

1. 면접 일정을 **온라인**으로 설정합니다.
2. 면접 시간이 **확정**되면 (후보자가 시간을 선택하거나 담당자가 확정하면), 줌 회의가 **자동으로** 만들어집니다.
3. 줌 링크가 후보자·면접관에게 **메일 + 캘린더 초대(.ics)** 로 자동 발송됩니다.

> 담당자가 따로 줌 링크를 만들 필요가 없습니다. 확정만 하면 끝입니다.

---

## 문제가 생겼을 때

| 이런 증상이면 | 이렇게 하세요 |
|---|---|
| 연결 테스트가 실패해요 | 값 3개 중 하나를 잘못 복사한 경우입니다. 앞뒤 빈칸 없이 다시 붙여넣어 보세요. |
| "권한 없음" 오류가 나요 | 1단계 ⑤의 회의 만들기 권한이 빠진 것입니다. 권한을 추가하고 다시 **활성화**하세요. |
| 활성화 버튼이 안 눌려요 | 빨간 표시된 빈 칸이 남아 있습니다. 모두 채운 뒤 다시 누르세요. |
| 회의가 40분 만에 끊겨요 | 줌 **무료 요금제**의 제한입니다. 유료(Pro 이상)로 올리면 해결됩니다. |
