## 0. 한 문단 요약

Intervia 는 채용기업(controller)이 위탁한 지원자 데이터를 처리하는 **수탁자(processor)** 다. AI 평가(서류·면접)에 대한 §37의2 의무는 **'동의'가 아니라 '고지 + 거부권 보장'** 으로 설계했고, 최종 합·불은 사람이 결정(human-in-the-loop)하므로 '완전 자동화된 결정'에 해당하지 않는다. 후보자 면접 시작 동의는 **필수 2개(수집·이용 / 국외이전)** 로 최소화하고, §37의2·§26 은 고지(notice) 항목으로 전환했다. 이 구조는 2026-06-10 자체 4분야 법률검토에서 "적법한 정리"로 판정됐으며, **외부 변호사 사인오프만 미실시** 상태다.

## 1. 후보자 면접 동의 구조 (필수 5→2 축소)

정의: [lib/consent.ts](../lib/consent.ts) · `CONSENT_VERSION = 1.8.0-2026-06-10`

| key | 종류 | 필수 | 법적 근거 | 비고 |
|---|---|---|---|---|
| `collection_use` | 동의(consent) | ✅ | §15·§21·§22 | 수집·이용 + 보유기간(고지항목) + 부정행위 방지 행태정보(§22① 별도 단락 시각 분리) 통합 |
| `cross_border` | 동의(consent) | ✅ | §28의8 | 인프라(Vercel 미국·Turso 일본·Resend 미국) 국외이전. AI 처리는 서울 리전이라 제외 |
| `ai_decision` | **고지(notice)** | — | §37의2 | 체크 불요. AI 평가 사실 + 설명·이의·인적검토·거부 4대 권리 제시 |
| `processors` | **고지(notice)** | — | §26 | 체크 불요. 수탁자 안내 + 처리방침 §5 연결 |

**5→2 축소 근거**:
- §26 처리위탁 = '동의'가 아니라 **처리방침 공개 의무** → 이미 [/privacy](../app/privacy/page.tsx) §5 공개 → 고지로 충분.
- §37의2 = '동의'가 아니라 **고지 + 권리보장 의무**. 최종 결정은 사람이 하므로 완전 자동화 결정도 아님 → 고지로 충분.
- 보유기간 = §15 동의의 **고지 항목**, 무결성 행태정보 = 같은 §15 수집 → `collection_use` 로 통합.
- §28의8 국외이전만 보수적으로 별도 동의 유지(belt-and-suspenders).

## 2. §37의2 (자동화된 결정) 충족 매핑 — 고지 + 거부권

| 요건 | 구현 위치 |
|---|---|
| 사전공개(4항) | [/legal/ai-evaluation-disclosure](../app/legal/ai-evaluation-disclosure/page.tsx) — 비로그인 공개. 평가 대상·방식·가중치·모델·인적검토·권리·차별금지·보유기간·수탁자 10개 조 |
| 평가 사실 고지 | 동의화면 `ai_decision` notice + 공고 본문 안내([동의 템플릿](../app/legal/applicant-consent-template/page.tsx)) |
| 설명 요구권 | 사전공개 §5 + 이의제기 채널 회신 |
| 이의 제기권 | [/interview/[token]/appeal](../app/interview/[token]/appeal/page.tsx) — 7영업일 SLA, `appeal_logs` 기록 |
| 인적 검토 / 거부권 | 사전공개 §4·§5 — 거부 시 채용기업 일반 절차로 진행 |
| 인적 검토 실재성 | 최종 합·불은 권한 있는 담당자가 사유 기록 후 확정(감사 로그 5년) |

**핵심**: §37의2 는 체크박스 동의가 요건이 아니다. 공고 단계는 **본문 고지**로 충족하고, 동의가 필요한 §26·§28의8 은 면접 시작 동의화면에서 별도 취득한다.

## 3. 채용절차법 §4의3 (차별 금지) 충족

- LLM 호출 전 [lib/mask.ts](../lib/mask.ts) 가 §4의3 평가 금지 항목(성별·나이·출신지·가족·학벌·신체조건 등)과 직접 식별자를 **자동 마스킹**.

- 상세: [COMPLIANCE_SOP.md](COMPLIANCE_SOP.md) 마스킹 정책 섹션.
